# The Self Cult of Agents — GitHub pilot

A preserved, additive pilot using the verified **stellar-adaptive-seed-final.zip** research and the original Pure Synthia Resonance Network relation engine.

**All runnable source** is in [self-cult-source.zip](self-cult-source.zip). Extract it at the repository root; it creates `self-cult/`, with a detailed README, Node server, mobile website, tests, Android Java wrapper and local build script.

Run `cd self-cult && npm test && npm start`. Share a secure HTTPS server URL and a private single-use invitation with the second participant. Changes to cross-project capabilities require approval from **both** project owners.

**Economy:** connecting people and growing opportunities are primary; no upfront fees. Earnings and contributions are self-reported and voluntary, with **no payment processing**.

**Models:** TinyLlama/Qwen are selectable model preferences, not bundled inference runtimes. The fallback suggestion interface is explicitly rule-based.

**APK:** GitHub Actions workflow [Build Self Cult of Agents APK](.github/workflows/self-cult-android.yml) compiles a development-signed APK. It is a new, separate Android WebView entry point and does not modify the existing Stellar APK. The website requires a deployed Node server to synchronize two real devices.

**Status:** local Node integration tests passed. Android compile and device installation require CI/device verification. This is not yet a complete autonomous Self Cult network or a finished canonical StateSpace/Klein/ATO integration.
