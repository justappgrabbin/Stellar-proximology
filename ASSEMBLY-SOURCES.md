## Status vocabulary

- PRESENT: source/application exists.
- PARTIALLY WIRED: some runtime paths exist but the complete path is not established.
- WIRED: real inputs and outputs are connected through the intended application flow.
- VERIFIED: the complete runtime path has been tested end-to-end with the expected result.
